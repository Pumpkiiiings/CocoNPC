## `/coconpc reload`

Re-reads configuration files and scans all animation files without restarting the server.

```bash
/coconpc reload
```

### What gets reloaded:

| Category | Files / Contents |
| :--- | :--- |
| `config.yml` | MineSkin key, view distance, editor steps, safety settings |
| `messages.yml` | Prefix, translation strings, MiniMessage formats |
| `animations/` | Scans all `.bbmodel` and `.json` animation files and registers new ones |
| `npcs/<id>.yml` | Updates positions, holograms, active animations, and action chains |
| `menus/` | Editor and hologram GUI layouts |

The MineSkin client is rebuilt as part of the reload, so a key pasted straight into `config.yml` takes effect immediately without a server restart.

<Callout type="info">
  Reloading does not cause existing NPCs to flicker or despawn.
</Callout>

---

## `/coconpc preload`

Uploads every `.png` in `plugins/CocoNPC/skins/` to MineSkin that is not already cached.

```bash
/coconpc preload
```

Both commands use the `CocoNPC.reload` permission.

### Why use preload?
Generating limb textures for new skins takes a few seconds. Running `/coconpc preload` beforehand ensures all local `.png` skins are fully cached and ready to spawn instantly.
