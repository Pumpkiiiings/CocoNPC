---
title: /coconpc action
description: Add, list, remove and clear click actions and conditions on an NPC.
---

Manages an NPC's click action list. For detailed behavior and examples, see the [Action Engine guide](/docs/actions).

---

## Syntax

```bash
/coconpc action <id> <add|list|remove|clear> [arguments...]
```

| Subcommand | Syntax | Description |
| :--- | :--- | :--- |
| `add` | `action <id> add <type> <value>` | Append an action to the end of the list. |
| `list` | `action <id> list` | View all configured actions with their index numbers. |
| `remove` | `action <id> remove <index>` | Delete one entry by its 1-based number (aliases: `del`, `delete`). |
| `clear` | `action <id> clear` | Delete every action on this NPC. |

---

## Supported Action Types

Write the type with or without brackets — `message` and `[message]` both work.

- **Actions:** `message`, `broadcast`, `chat`, `console`, `player`, `title`, `subtitle`, `actionbar`, `sound`, `teleport`, `potion`, `heal`, `feed`, `give_item`, `take_item`, `give_exp`, `take_exp`, `server`, `animate`
- **Conditions:** `require_permission`, `require_money`, `cooldown`

<Callout type="info">
  `connect` is accepted as an alias for `server`. `server` supports both **Velocity** and **BungeeCord** proxies.
</Callout>

---

## Examples

```bash
# Greet the player
/coconpc action 1 add message <yellow>Welcome to the city, <player>!

# Play an animation on click
/coconpc action 1 add animate 1 wave

# Play a sound effect
/coconpc action 1 add sound entity.player.levelup 1.0 1.0

# Run a console reward command
/coconpc action 1 add console eco give <player> 100

# Enforce a 30-minute cooldown
/coconpc action 1 add cooldown 30m

# Send player to a backend server
/coconpc action 1 add server survival-2
```

---

## Reviewing and Removing

```bash
# List all actions
/coconpc action 1 list

# Remove entry #2
/coconpc action 1 remove 2

# Clear all actions
/coconpc action 1 clear
```

Removing an entry re-indexes subsequent actions, so run `/coconpc action <id> list` again before removing another entry.
