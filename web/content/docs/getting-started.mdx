## 1. Requirements & Installation

CocoNPC uses packet-based Display Entities for ultra-high performance with zero server entity tick lag.

### Requirements:
- **Paper / Purpur / Folia:** 1.21 or newer (up to 26.2+)
- **Java:** 21 or newer
- **PacketEvents:** 2.13.0+ (Required dependency)
- **PlaceholderAPI:** (Optional, needed for `%vault_eco_balance%` money conditions)

### Installation:
1. Download [PacketEvents](https://ci.codemc.io/job/retrooper/job/packetevents/) and place it into your `plugins/` folder.
2. Download `CocoNPC-1.2.2.jar` and place it into your `plugins/` folder.
3. Start or restart your server.

---

## 2. Set Your MineSkin API Key

CocoNPC splits player skins into individual limb textures and uploads them using MineSkin. A free MineSkin API key is required to generate new skins.

1. Get a free API key at [mineskin.org/account](https://mineskin.org/account).
2. Set your key directly in-game:
   ```bash
   /coconpc setkey your_api_key_here
   ```
   *(Or add it to `plugins/CocoNPC/config.yml` under `mineskin.api-key` and run `/coconpc reload`)*

<Callout type="info">
  Already cached skins in `skins.yml` do not require an active API key to spawn. The key is only needed when generating a brand-new skin for the first time.
</Callout>

---

## 3. Spawn Your First NPC

Stand at your desired location facing the direction you want the NPC to look towards, then run:

```bash
/coconpc create 1 Notch
```

- `1`: The unique numeric ID for your NPC.
- `Notch`: The skin (supports premium player usernames, direct texture URLs, or local `.png` filenames in `plugins/CocoNPC/skins/`).

You can also specify a custom scale multiplier as an optional 3rd parameter:
```bash
/coconpc create 2 Notch 1.5   # 1.5x scale
```

## 4. Customize Your NPC

| What you want to do | Command / Shortcut |
| :--- | :--- |
| **Open the 3D In-World Editor** | `/coconpc edit 1` *(or Shift + Right-Click the NPC)* |
| **Play a Blockbench Animation** | `/coconpc animate 1 <name>` (see [Animations Guide](/docs/animations)) |
| **Apply a Preset Pose** | `/coconpc pose 1 <stand\|sit\|lay\|wave\|salute\|crossed_arms>` |
| **Equip an Item in Hand** | Hold the item and run `/coconpc item 1 right` *(or left)* |
| **Configure Click Actions** | `/coconpc action 1 add ...` (see [Action Engine](/docs/actions)) |
| **Change Hologram Text** | Shift + Right-Click the Hologram button in `/coconpc edit 1` |
