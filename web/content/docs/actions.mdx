---
title: Action Engine
description: Bind clicks to messages, commands, sounds, animations, server transfers, and conditions.
---

An NPC's actions are an ordered list. When a player clicks the NPC, CocoNPC executes the list from top to bottom.

Actions can perform tasks (sending messages, running commands, playing sounds, triggering animations) or act as **conditions** (checking permissions, money, or cooldowns) that stop the chain if requirements aren't met.

```bash
/coconpc action <id> add <type> <value>
```

---

## Action Tags Reference

| Tag | What it does | Example |
| :--- | :--- | :--- |
| `[message]` | Sends a private message to the player. | `[message] <yellow>Welcome back, <player>!` |
| `[broadcast]` | Sends a message to the entire server. | `[broadcast] <gold><player> discovered a secret!` |
| `[chat]` | Forces the player to say something in public chat. | `[chat] I want to join the guild!` |
| `[console]` | Runs a command from the server console. | `[console] eco give <player> 100` |
| `[player]` | Forces the player to run a command as themselves. | `[player] spawn` |
| `[title]` | Displays a large on-screen title. | `[title] <gold><bold>DUNGEON` |
| `[subtitle]` | Displays a subtitle under the title. | `[subtitle] <gray>Good luck, <player>` |
| `[actionbar]` | Sends a message directly to the player's action bar. | `[actionbar] <green>+100 Coins!` |
| `[sound]` | Plays a Minecraft sound for the player (volume and pitch optional). | `[sound] entity.player.levelup 1.0 1.0` |
| `[teleport]` | Teleports the player to coordinates (`world,x,y,z` or `world,x,y,z,yaw,pitch`). | `[teleport] world,100,64,200` |
| `[give_item]` | Gives an item to the player (material, amount). | `[give_item] diamond 2` |
| `[take_item]` | Removes an item from the player's inventory. | `[take_item] iron_ingot 5` |
| `[potion]` | Applies a potion effect (`effect, duration_ticks, amplifier`). | `[potion] speed 200 1` |
| `[heal]` | Restores the player's health to maximum. | `[heal]` |
| `[feed]` | Restores the player's hunger and saturation to full. | `[feed]` |
| `[give_exp]` | Grants raw experience points. | `[give_exp] 250` |
| `[take_exp]` | Removes experience points. | `[take_exp] 50` |
| `[server]` | Connects player to a proxy backend server (**Velocity** and **BungeeCord** supported). | `[server] survival-1` |
| `[animate]` | Triggers a Blockbench animation on an NPC (or `stop`). | `[animate] 1 wave` |

<Callout type="info">
  `[title]` and `[subtitle]` are automatically buffered and sent together as a single smooth screen display.
</Callout>

## Conditions (Gates)

Conditions do not produce output on their own. If a condition fails, **the rest of the action list is immediately cancelled**.

| Condition Tag | Requirement | Example |
| :--- | :--- | :--- |
| `[require_permission]` | Player must have the specified permission node. | `[require_permission] ranks.vip` |
| `[require_money]` | Player's balance must be at least this amount (via Vault & PAPI). | `[require_money] 500` |
| `[cooldown]` | Player must wait the specified duration before using again. | `[cooldown] 1h` |

### Cooldown Duration Formats

- `30s` = 30 seconds
- `5m` = 5 minutes
- `2h` = 2 hours
- `1d` = 1 day
- Plain numbers like `60` are read as seconds.

Cooldowns are tracked individually per player and per NPC, and persist across server restarts in `plugins/CocoNPC/cooldowns.yml`.

<Callout type="warn">
  **Order Matters! Always put cooldown last among conditions.**  
  `[cooldown]` starts the timer the instant it is evaluated. If you place `[cooldown]` before `[require_money]` and the player lacks enough money, they will still lose their cooldown! Put checks first, cooldown last before rewards.
</Callout>

## Placeholders

CocoNPC replaces these placeholders in every action text:

| Placeholder | Result |
| :--- | :--- |
| `<player>` | The player's username |
| `%player_name%` | The player's username |

If **PlaceholderAPI** is installed, all PAPI placeholders (such as `%vault_eco_balance%`, `%player_ping%`, etc.) are fully supported.

## Common Examples

### 1. BungeeCord / Velocity Server Portal
Transfers the player to another server with a nice sound and title:
```bash
/coconpc action 1 add sound entity.enderman.teleport 1.0 1.2
/coconpc action 1 add title <aqua><bold>CONNECTING...
/coconpc action 1 add subtitle <gray>Sending you to Survival
/coconpc action 1 add server survival
```

### 2. Daily Reward NPC
Gives items once every 24 hours:
```bash
/coconpc action 2 add cooldown 24h
/coconpc action 2 add sound entity.player.levelup 1.0 1.0
/coconpc action 2 add console give <player> diamond 3
/coconpc action 2 add message <green>Here is your daily reward of 3 diamonds, <player>!
```

### 3. Interactive Animated Greeting
When clicked, the NPC waves and speaks:
```bash
/coconpc action 3 add animate 3 wave
/coconpc action 3 add sound entity.villager.ambient 1.0 1.0
/coconpc action 3 add message <yellow>Hello there, traveler <player>!
```

### 4. Paid VIP Teleport
Checks rank, checks money, charges the player, and teleports them:
```bash
/coconpc action 4 add require_permission rank.vip
/coconpc action 4 add require_money 250
/coconpc action 4 add cooldown 5m
/coconpc action 4 add console eco take <player> 250
/coconpc action 4 add message <green>Paid $250! Teleporting to the VIP lounge...
/coconpc action 4 add teleport vip_world,0,70,0
```

## Managing Actions

```bash
# View all configured actions with their index numbers
/coconpc action 1 list

# Remove action #3 (index is 1-based)
/coconpc action 1 remove 3

# Wipe all actions from the NPC
/coconpc action 1 clear
```

Actions are stored directly in `plugins/CocoNPC/npcs/<id>.yml`. You can also edit them by hand in the file and run `/coconpc reload`.
