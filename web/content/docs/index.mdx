**CocoNPC** is a modern Minecraft NPC plugin built completely on native **Display Entities** and network packets.

Instead of spawning heavy living mobs with pathfinding AI, CocoNPC streams lightweight display packets only to nearby players. This means having 100 NPCs costs the exact same server tick time as having zero!

---

## ⚡ Core Features

1. **Zero Entity Lag (0 Ticks):** NPCs exist purely as client packets. They do not pathfind, collide, or slow down server MSPT.
2. **Vanilla Blockbench Animations:** Play native `.bbmodel` or Bedrock `.json` animations smoothly with mathematical Slerp quaternion interpolation. **No resource packs required!**
3. **Persistent Animations:** Animations automatically loop and resume across server restarts and world reloads.
4. **Interactive 3D In-World Editor:** Pose limbs, bend elbows and knees, and reposition parts directly in-game using mouse scroll wheels.
5. **Powerful Action Engine:** Bind clicks to console commands, player commands, sounds, actionbars, titles, permissions, money checks, and Velocity/BungeeCord proxy transfers.
6. **Clean Architecture:** Every NPC is safely isolated into its own file (`plugins/CocoNPC/npcs/<id>.yml`). An accidental `/kill @e` will never delete your NPCs.

## Requirements

| Requirement | Supported Version | Details |
| :--- | :--- | :--- |
| **Server** | Paper / Purpur / Folia **1.21+** (up to 26.2+) | Required |
| **Java** | **21+** | Required |
| **PacketEvents** | **2.13.0+** | Required hard dependency |
| **MineSkin API key** | Free key from [mineskin.org](https://mineskin.org/account) | Required to generate new skins |
| **PlaceholderAPI** | Latest | Optional (for `%vault_eco_balance%`) |

<Callout type="error" title="Note for Bedrock Players (Geyser)">
  Because Minecraft Display Entities are not rendered by Bedrock clients, Bedrock players cannot see or interact with these NPCs. CocoNPC automatically detects Bedrock players via Floodgate and prevents invisible ghost clicks.
</Callout>
