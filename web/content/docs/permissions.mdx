---
title: Permissions
description: All permission nodes registered by CocoNPC and what they unlock.
---

All permission nodes default to **server operators (OP)**.

`CocoNPC.admin` is a wildcard parent of every other node — granting it grants full access to all commands and settings.

---

## Permission Nodes Reference

| Permission Node | Unlocks |
| :--- | :--- |
| `CocoNPC.admin` | Full administrator access to all commands, plus `/coconpc setkey`. |
| `CocoNPC.spawn` | `/coconpc create`, `/coconpc spawn` |
| `CocoNPC.list` | `/coconpc list` |
| `CocoNPC.tp` | `/coconpc tp`, `/coconpc teleport` |
| `CocoNPC.tphere` | `/coconpc tphere` |
| `CocoNPC.npc.edit` | `/coconpc edit`, and shift + right-clicking an NPC to open the editor |
| `CocoNPC.npc.delete` | `/coconpc delete` |
| `CocoNPC.animate` | `/coconpc animate`, `/coconpc animation_stop` |
| `CocoNPC.action` | `/coconpc action` (add, list, remove, clear) |
| `CocoNPC.pose` | `/coconpc pose` |
| `CocoNPC.resize` | `/coconpc resize` |
| `CocoNPC.item` | `/coconpc item`, `/coconpc equip` |
| `CocoNPC.skin` | `/coconpc skin` |
| `CocoNPC.clone` | `/coconpc clone` |
| `CocoNPC.viewdistance` | `/coconpc viewdistance` |
| `CocoNPC.reload` | `/coconpc reload`, `/coconpc preload` |

---

## Helpful Details

- **Admin Only:** `/coconpc setkey` strictly requires `CocoNPC.admin` because it writes your private MineSkin API key to disk.
- **In-World Editor Guard:** `CocoNPC.npc.edit` is checked both by the command and by Shift + Right-Clicking an NPC in the world.
- **Player Interactions:** Regular players **do not need any permissions** to click or interact with NPCs! If you want to restrict an NPC to certain players, use the `[require_permission]` condition tag in its action list (see [Action Engine](/docs/actions)).
- **Tab Completion:** Tab suggestions dynamically filter out subcommands the player does not have permission to execute.

---

## Example: Builder Role

If you want builders to pose, skin, and place NPCs without letting them run console commands or delete critical server NPCs:

```yaml
# In LuckPerms or your permissions plugin
permissions:
  - CocoNPC.spawn
  - CocoNPC.npc.edit
  - CocoNPC.animate
  - CocoNPC.pose
  - CocoNPC.resize
  - CocoNPC.item
  - CocoNPC.skin
  - CocoNPC.clone
  - CocoNPC.list
  - CocoNPC.tp
```
